# Setup Guide

This guide covers local development, Supabase, admin access, contact email delivery, image uploads, and Vercel deployment.

## Requirements

- Node.js 24.x
- npm 10.9.2 or compatible npm 10 version
- A Supabase project for property data and image storage
- An SMTP account for the contact form
- A Vercel account for production deployment

## 1. Install the project

From the project directory:

```powershell
npm install
```

Start the development server:

```powershell
npm run dev
```

Open `http://localhost:3000`.

## 2. Configure Supabase

1. Create a Supabase project.
2. Open the Supabase SQL Editor.
3. Run the complete contents of `database/schema.sql`.
4. Copy the project URL and server-only secret key.

Use the secret key only on the server. Do not use a browser/publishable key for `SUPABASE_SECRET_KEY`.

## 3. Create local environment variables

Copy the example file:

```powershell
Copy-Item .env.example .env.local
```

Set these values in `.env.local`:

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SECRET_KEY=your_server_only_supabase_secret
```

The following values are generated by the admin setup command and must not be invented manually:

```env
AUTH_PEPPER=
ADMIN_USERNAME_DIGEST=
ADMIN_PASSWORD_HASH=
DATA_ENCRYPTION_KEY=
```

## 4. Create the admin login

Run this command in an interactive terminal:

```powershell
npm run create-admin
```

Enter:

- An admin username between 4 and 150 characters.
- An admin password with at least 14 characters.

The command writes the hashed login and encryption keys to `.env.local`. Never commit `.env.local` or share the plain password.

The admin area is available at:

```text
http://localhost:3000/admin/login
```

## 5. Configure contact email

The contact form uses Nodemailer over SMTP. Add the SMTP details to `.env.local`:

```env
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=office@example.com
SMTP_PASSWORD=your_smtp_password
SMTP_FROM_EMAIL=office@example.com
CONTACT_EMAIL=office@example.com
```

`CONTACT_EMAIL` is the office inbox that receives website enquiries. Use port `465` for SMTP providers that require implicit TLS; other common providers use port `587`.

Do not commit SMTP passwords or any real credentials.

## 6. Test locally

Run the development server:

```powershell
npm run dev
```

Check the following:

1. Open `/contact`.
2. Submit a test message.
3. Confirm it arrives at `CONTACT_EMAIL`.
4. Open `/admin/login`.
5. Create a draft property with a small JPG, PNG, WEBP, AVIF, or GIF image.
6. Edit the property and confirm the image preview and save flow.
7. Publish the property and check `/properties`.

Image uploads are limited to 4MB and are validated on the server.

## 7. Validate a production build

```powershell
npm run build
npm run start
```

Then open `http://localhost:3000` in a browser while the production server is running.

## 8. Deploy to Vercel

1. Push the repository to GitHub.
2. Import the repository into Vercel.
3. Select the Next.js framework preset.
4. Use Node.js 24.x.
5. Keep the build command as `npm run build`.
6. Add the server environment variables below in Vercel Project Settings under Environment Variables.
7. Apply them to Production and Preview if both environments are needed.
8. Deploy or redeploy the project.

Required Vercel environment variables:

```text
SUPABASE_URL
SUPABASE_SECRET_KEY
AUTH_PEPPER
ADMIN_USERNAME_DIGEST
ADMIN_PASSWORD_HASH
DATA_ENCRYPTION_KEY
SMTP_HOST
SMTP_PORT
SMTP_USER
SMTP_PASSWORD
SMTP_FROM_EMAIL
CONTACT_EMAIL
```

Keep `DATA_ENCRYPTION_KEY` unchanged after data is created. Changing it makes existing encrypted property records unreadable.

## 9. Domain setup

In Vercel Project Settings, add:

- `executeltd.co.uk`
- `www.executeltd.co.uk`

Follow the DNS records shown by Vercel. The domain owner must make the DNS changes.

## Security checklist

- Never commit `.env.local`.
- Never expose `SUPABASE_SECRET_KEY` in client code.
- Never expose SMTP credentials in the browser.
- Keep `DATA_ENCRYPTION_KEY` backed up securely.
- Use a strong admin password of at least 14 characters.
- Restrict access to `/admin/login` credentials.
- Keep the Supabase service key and SMTP password in Vercel server environment variables only.
